CMP 170HX fuse planner

For the NVIDIA CMP 170HX (GA100) 8 GB card. Paste a read of your own card to see what its fuses allow and, when the read is complete, the exact FF record words a burn would need.

Burns are permanent

  • An FF record cannot be undone. A wrong word can leave a card at PCIe x1, without a driver, or not booting at all.
  • Plan only from your own cold read of this card. Never use another card's read, plan or record words, even from the same batch.
  • Check every plan with ffcalc: python3 -m ffcalc sim card.json plan.json must end in SIMULATION OK.
  • Have a second person review every word before you burn it.

This page writes nothing to any card and gives no burn commands.

Nothing leaves this browser. The page loads no scripts, fonts or data from anywhere, and its content security policy blocks every network request. Your read is processed on this device and is not stored.

Your read

  • an ffcalc card dump: JSON with sku, option_words and ff_rows
  • a vfi_snap.py --rows snapshot: JSON whose two row reads matched (rows_match true)
  • a rows file: one <row> <value> pair per line, as ffcalc reads it (decoded view only)
How this page plans, and when it refuses
  • Targets follow ffcalc's rule: each floorsweep field's target is its own defective mask, so only units that are not marked defective are cleared. The four PCIe link-speed fields go to 0.
  • Records come only from a complete read: every FF row from 222 to 486 present, unburnt rows as 0. One record per changed 16-bit block; every other bit of that block keeps the value the existing records give it. New rows start right after the last used row.
  • Order: compute with the GPC block (chain 1 block 8) last, then memory with the FBP block (chain 1 block 19) last, then PCIe. A block with changes from two sets is written once, at its earlier position, with a warning.
  • Simulation: before anything is shown, the existing rows plus the plan are replayed and every field is decoded and compared with its target. Every word must have bit 5 clear, encode and decode back to itself, and land on a blank row inside 222 to 486.
  • Refusals: a partial or missing read; a vfi_snap read whose two passes differ; a word with bit 5 set among the FF rows; a live mask that the FF rows do not reproduce; a target that would enable a unit, or a slice of an FBP, marked defective; a block that needs a change but has no record to read its other bits from; a missing mask for a ticked group; too few rows.
  • Left out on purpose: the whole-word PCIE_MAGIC_BITS_D rewrite, the device ID fields and bit 1 of chain 2 block 39. NVLink and SYS_PIPE are off by default: clearing them has not been shown to turn those features on.

PCIe fuse locations as measured on burned 8 GB cards: OPT_DISABLE_GEN3_SPEED is chain 2 block 39 bit 9; PCIE_MAGIC_BITS_D bit 25 is chain 2 block 47 bit 3, with the register equal to (block47 << 22) | (block46 << 6); OPT_PCIE_BOOT_GEN3_DIS is chain 2 block 49 bit 7; OPT_PCIE_BOOT_GEN23_DIS is chain 2 block 49 bit 6.
